# NETRUNNER 2088 — десктопное приложение

Выдуманный киберпанк-симулятор хакера. Два способа запустить на компьютере.

## Способ 1 — просто открыть файл (самый быстрый, ничего ставить не надо)

`index.html` — это уже готовая игра. Открой его на компьютере:

- **Windows:** щёлкни по `index.html` правой кнопкой → «Открыть с помощью» → твой браузер (Chrome, Edge). Или перетащи файл в окно браузера.
- **macOS:** щёлкни правой кнопкой → «Открыть в программе» → Safari/Chrome.

Для вида «настоящего приложения» в браузере нажми **F11** — полный экран.
Игра работает офлайн, прогресс сохраняется на этом компьютере.

## Способ 2 — собрать настоящее приложение в своём окне (Electron)

Нужен установленный [Node.js](https://nodejs.org).

```bash
cd desktop-app
npm install        # один раз скачает Electron
npm start          # запустит игру в отдельном окне-приложении
```

Чтобы собрать установщик (`.exe` для Windows, `.dmg` для macOS, `.AppImage` для Linux):

```bash
npm run build          # под текущую систему
npm run build:win      # только Windows
npm run build:mac      # только macOS
npm run build:linux    # только Linux
```

Готовые установщики появятся в папке `dist/`.

## Управление

- Команды печатаются в терминале. `help` — список.
- `↑ / ↓` — история команд, `Tab` — автодополнение.
- Клик по узлу на карте сети = разведка цели (`scan`).
- `F11` — полный экран.

Это выдуманный мир: ни одной реальной системы и ни одной настоящей команды атаки здесь нет — только головоломки и сюжет.
